# 🍿 Watch Together Core (watchtogether)

### Lightweight WebSocket-Based Synchronized Media Playback Engine for Virtual Watch Parties

[![Python 3.9+](https://img.shields.io/badge/Python-3.9%2B-blue.svg?logo=python&logoColor=white)](https://python.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Synchronize video streaming across multiple remote viewers in real time.**  
*Sub-second drift correction (<1.0s), room state extrapolation, and decentralized host handoff for Telegram WebApps and browser players.*

---

## 📦 Installation

```bash
pip install git+https://github.com/Kaio-Comk/Watch-Together-Core.git
```
